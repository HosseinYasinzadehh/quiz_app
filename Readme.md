# 🧠 Quiz App

A simple command-line quiz application built with Python.

The app loads quiz questions from a JSON file, presents them one by one in a randomized order, checks the user's answers, and displays the final score and percentage.

## ✨ Features

- Loads questions from a JSON file
- Randomizes question order
- Displays multiple-choice questions
- Validates user input
- Handles invalid input without crashing
- Tracks correct and incorrect answers
- Calculates the final percentage
- Allows the user to play again

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

    git clone https://github.com/HosseinYasinzadehh/quiz_app

Go into the project directory:

    cd quiz_app

Run the quiz:

    python main.py
